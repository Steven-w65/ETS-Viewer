# ETS-Viewer

A local, read-only ETS question and answer viewer built with Python
and PySide6. The application and complete usage instructions are in
[ETS-Viewer](ETS-Viewer/README.md).

```powershell
cd ETS-Viewer
python -m pip install -r requirements.txt
python main.py "C:\Users\steve\AppData\Roaming\ETS"
```
